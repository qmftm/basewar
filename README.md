# BaseWar (기지전쟁) Minecraft Plugin

## 프로젝트 소개
BaseWar는 팀 기반의 마인크래프트 PvP 플러그인입니다. 각 팀은 자신들의 신호기(비콘)를 보호하면서 상대 팀의 신호기를 파괴하는 것을 목표로 합니다. 최후까지 살아남는 팀이 승리합니다.

---

## 주요 기능

### 신호기 시스템
- 게임 시작 시 각 팀의 랜덤 플레이어에게 신호기가 지급됩니다.
- 신호기 설치 시 아래에 파괴 불가능한 3×3 철 블록 기반이 자동 생성됩니다.
- 신호기 주변에 팀 색깔 유리 블록이 장식으로 설치됩니다.
- 팀원이 신호기를 설치하면 같은 팀원들에게 좌표가 자동 안내됩니다.
- 신호기는 폭발로 파괴되지 않습니다.
- 적 팀의 신호기를 채굴할 때 채굴 피로 I 효과가 적용됩니다.
- 신호기가 파괴되면 아래 철 블록 기반과 주변 유리 블록도 함께 제거됩니다.

### 리스폰 시스템
- 팀 신호기가 살아있는 동안 사망 시 5초 대기 후 신호기 주변 랜덤 위치에서 리스폰됩니다.
- 신호기 설치 전 사망 시 글로벌 스폰 지점으로 일반 리스폰됩니다.
- 신호기가 파괴된 팀의 플레이어는 사망 시 최종 탈락하여 관전 모드로 전환됩니다.

### 무적 시간
- 게임 시작 시 설정된 시간(기본 15분) 동안 모든 데미지(PvP, 낙사, 용암, 익사, 몬스터 등)로부터 보호됩니다.
- 무적 시간 동안 신호기 파괴/손상도 불가합니다.
- 남은 시간이 보스바에 분/초 단위로 표시되며 시간이 줄수록 초록 → 노랑 → 빨강으로 변합니다.
- 보스바는 팀 여부와 무관하게 서버의 모든 플레이어에게 표시됩니다.

### 팀 시스템
- 같은 팀원끼리 공격할 수 없습니다.
- 팀 이름은 각 팀의 색상으로 채팅·탭 목록에 표시됩니다.
- `/bw chat` 명령어로 팀 전용 채팅 모드를 켜고 끌 수 있습니다.
- 게임 종료 시 모든 플레이어의 팀이 자동으로 해제됩니다.

## 게임 모드

### 기본 (DEFAULT)
기지전쟁의 기본 규칙입니다. 신호기를 설치하고 적 팀의 신호기를 파괴하세요. 신호기가 파괴된 팀은 리스폰할 수 없습니다.

### 점령전 (CONQUEST)
신호기 주변 구역을 점령하는 모드입니다.

- 신호기 주변 구역(기본 반경 15블록 정육면체)에 아군이 적보다 많으면 점령이 진행됩니다.
- 점령도가 100%에 도달하면 해당 신호기를 획득하고 상대 팀은 탈락합니다.
- 아군 다수 방어 시 점령도가 감소합니다(감소 속도는 점령 속도의 절반).
- 동수일 때는 점령도가 멈춥니다(보스바가 흰색으로 변경).
- **구역을 나갔다 돌아와도 점령도가 유지됩니다.**
- **다른 팀이 구역에 진입하면 기존 팀의 게이지를 먼저 감소시키고, 0%가 된 후 자신의 게이지가 쌓입니다.**
- 아무도 없을 때는 점령도가 그대로 유지됩니다.
- 점령 진행도는 팀별 보스바로 모든 플레이어에게 표시됩니다.

### 하드코어 (HARDCORE)
- 사망 시 인벤토리가 바닥에 떨어지지 않고 보호됩니다(경험치 포함).
- 부활 쿨타임이 없습니다(즉시 관전 모드로 전환되어 대기).
- **팀원이 자기 팀 신호기를 우클릭하면 부활 GUI가 열립니다.**
- GUI에서 죽은 팀원을 클릭하면 다이아몬드를 소모해 부활시킵니다(기본 32개, config에서 변경 가능).
- 부활 시 사망 전 인벤토리를 그대로 들고 신호기 근처에 소환됩니다.
- 신호기가 파괴되면 부활 대기 중인 팀원도 최종 탈락합니다.
- 신호기 설치 전 사망 시에는 일반 리스폰됩니다.

## 설정 (config.yml)
플러그인 첫 실행 시 `plugins/BaseWar/config.yml`이 생성됩니다. `/bw reload`로 서버 재시작 없이 즉시 반영할 수 있습니다.

```yaml
# 사용될 팀 목록
teams:
  RED:
  BLUE:
  YELLOW:
  GREEN:

# 게임 시작 후 무적 시간 (초 단위, 기본 900초 = 15분)
invincibility-duration: 900

# 신호기 설치 가능 범위 제한
beacon-placement-restrictions:
  enabled: true
  min-x: -1000
  max-x: 1000
  min-y: 0
  max-y: 256
  min-z: -1000
  max-z: 1000

# 점령전 모드 설정
conquest:
  capture-radius: 15   # 점령 구역 반경 (블록)
  capture-rate: 5.0    # 초당 점령도 증감량 (%)

# 하드코어 모드 설정
hardcore:
  revive-cost: 32      # 부활에 필요한 다이아몬드 개수
```

| 항목 | 설명 |
|------|------|
| `teams` | 게임에 참여할 팀 목록 |
| `invincibility-duration` | 게임 시작 후 무적 시간(초) |
| `beacon-placement-restrictions` | 신호기 설치 가능 좌표 범위 |
| `conquest.capture-radius` | 점령전 구역 반경(블록) |
| `conquest.capture-rate` | 점령전 초당 점령도 변화량(%) |
| `hardcore.revive-cost` | 하드코어 부활 시 필요한 다이아몬드 개수 |

`global-spawn`과 `kit`은 인게임 명령어로 자동 저장됩니다.

## 명령어

### 플레이어 명령어
| 명령어 | 설명 |
|--------|------|
| `/bw chat` | 팀 채팅 모드 켜기/끄기 |
| `/팀채팅` | 팀 채팅 모드 켜기/끄기 (`/bw chat` 단축키) |
| `/팀챗` | 팀 채팅 모드 켜기/끄기 (`/bw chat` 단축키) |

### 관리자 명령어 (`basewar.admin` 권한 필요)
| 명령어 | 설명 |
|--------|------|
| `/bw start` | 기지전쟁 시작 (5초 카운트다운 후 시작) |
| `/bw stop` | 진행 중인 게임 강제 종료 |
| `/bw reload` | `config.yml`을 즉시 리로드 |
| `/bw config setspawn` | 현재 위치를 게임 시작 글로벌 스폰으로 설정 |
| `/bw config inv <초>` | 무적 시간 설정 (예: `/bw config inv 300`) |
| `/bw config kit` | 게임 시작 시 지급 아이템 설정 GUI 열기 |
| `/bw config gamemode` | 게임 모드 선택 GUI 열기 (기본/점령전/하드코어) |
| `/bw team set <플레이어> <팀>` | 특정 플레이어를 팀에 배정 |
| `/bw team random [팀 수]` | 모든 플레이어를 무작위 배정 (숫자 생략 시 기본 2팀) |
| `/bw spectator <플레이어>` | 관전 모드 전환/복귀 토글 |

### `/bw spectator` 상세
- 게임 중 실행 시 해당 플레이어를 관전 모드로 전환합니다. 원래 팀 정보가 저장되고 탭 목록에 회색 `[관전]` 이름으로 표시되며 자유롭게 이동할 수 있습니다.
- 이미 관전 중인 플레이어에게 다시 실행하면 원래 팀으로 복귀시킵니다.
- 원래 팀이 탈락한 경우 복귀가 불가하며 관전 모드를 유지합니다.
- **팀의 마지막 생존자는 관전 모드로 전환할 수 없습니다.** 항상 팀에 최소 1명의 생존자가 유지됩니다.
- 게임 종료 시 관전 상태는 자동으로 초기화됩니다.
